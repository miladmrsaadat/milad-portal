راهنمای اجرای پورتال میلاد
==========================

این راهنما برای نسخهٔ داخل پوشهٔ multi-file است.
لازم نیست هیچ دستوری بنویسی. فقط با ماوس کار کن.

۱) فایل zip را از حالت فشرده خارج کن
   روی فایل zip راست‌کلیک کن و Extract All / Extract here را بزن.
   پوشه را باز کن، بعد وارد پوشهٔ multi-file شو.

۲) پورتال را روشن کن
   روی فایل «اجرا» (اجرا.bat) دوبار کلیک کن.
   یک پنجره باز می‌شود و بعد مرورگر خودش صفحه را باز می‌کند.
   آدرس باید شبیه این باشد:  http://localhost:8765
   (اگر آن شماره اشغال باشد، خودش شمارهٔ دیگری را امتحان می‌کند.)

۳) اگر ویندوز هشدار داد (SmartScreen)
   گاهی پنجره‌ای می‌آید که «Windows protected your PC» یا متن فارسی شبیه آن است.
   روی More info / اطلاعات بیشتر بزن، بعد Run anyway / اجرا را بزن.
   این برنامه مال خودت است و فقط روی همین کامپیوتر کار می‌کند؛ به اینترنت وصل نمی‌شود.

۴) نصب به‌عنوان برنامه (اختیاری، ولی مفید)
   وقتی صفحه در Chrome یا Edge باز شد، به نوار آدرس بالای مرورگر نگاه کن.
   یک آیکون نصب (یا یک علامت + / کامپیوتر کوچک) می‌بینی. روی آن بزن و Install / نصب را تأیید کن.
   اگر آن آیکون نبود: منوی سه نقطهٔ مرورگر را باز کن و «Install app» یا «نصب پورتال» را بزن.
   بعد از نصب، می‌توانی پورتال را مثل یک برنامه از منوی استارت باز کنی.
   یادآوری‌های مرورگر هم روی این حالت بهتر کار می‌کنند.

۵) بستن
   پنجره‌ای را که بعد از دوبار کلیک روی «اجرا» باز شد، ببند.
   یا روی فایل «توقف» (توقف.bat) دوبار کلیک کن.
   بعد از بستن، اگر برنامه را نصب کرده‌ای، برای استفادهٔ دوباره اول دوباره «اجرا» را بزن تا چراغ سرور روشن شود.

۶) داده‌های قبلی‌ات کجا هستند؟
   اگر قبلاً فایل Portal-Milad.html را مستقیم (با دوبار کلیک) باز می‌کردی،
   آن داده‌ها در آدرس file:// ذخیره شده‌اند.
   آدرس http://localhost یک جای ذخیرهٔ جداست؛ پس داده‌ها خودبه‌خود نمی‌آیند.

   انتقال خیلی ساده است:
   الف) همان فایل قدیمی را باز کن.
   ب) از منوی تنظیمات (چرخ‌دنده) «خروجی پشتیبان» را بزن و فایل JSON را ذخیره کن.
   ج) پورتال را با «اجرا» باز کن.
   د) دوباره از منوی تنظیمات «ورود فایل پشتیبان» را بزن و همان فایل را انتخاب کن.

نکته: این روش کاملاً روی کامپیوتر خودت است و به سرور بیرون وصل نمی‌شود.
